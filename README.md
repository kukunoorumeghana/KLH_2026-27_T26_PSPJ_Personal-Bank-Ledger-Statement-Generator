Abstract:
The Personal Bank Ledger and Statement Generator is a small project made to help people keep track of their money. It lets you enter simple details like how much you deposit, how much you withdraw, the date of the transaction, and a short note about it. These details are stored in arrays or lists so that all transactions can be kept together in order.
The program uses basic methods to do its work. One method adds a new transaction, another calculates the current balance, and another shows a statement of all the transactions. With these simple steps, the project can create a clear record of your bank activity.
This project is beginner friendly because it uses only basic inputs, arrays, and simple methods, making it easy to understand while still being useful for learning how to manage data and produce simple bank statements.
